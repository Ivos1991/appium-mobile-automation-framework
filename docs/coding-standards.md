# Coding Standards

- Prefer clarity over cleverness.
- Keep abstractions shallow and explicit.
- Put selectors only in screen objects.
- Keep screens UI-focused and free of business decisions.
- Keep flows responsible for orchestration and state transitions.
- Keep step definitions thin and readable.
- Add helpers only when they remove real duplication.
- Use TypeScript strict mode and keep typecheck clean.
- Keep reporting useful, not verbose.
- Extend the framework by vertical slices, not by broad scaffolding.
